
# CIA Triad

## Definition
The CIA Triad is a basic security model used to protect information and systems. It has three principles: Confidentiality, Integrity, and Availability.

## Key points
- Confidentiality means keeping information private and allowing only authorized people to access it.
- Integrity means protecting information from unauthorized changes or deletion.
- Availability means making sure systems and data are accessible when users need them.
- Encryption helps protect confidentiality.
- Hashing and digital signatures can help verify integrity.
- Backups and redundancy help maintain availability.

## Example
A hospital protects patient records using access controls (Confidentiality), prevents unauthorized changes to medical records (Integrity), and keeps its computer systems running so doctors can access patient information (Availability).

## Exam tip
Do not confuse the three principles. Confidentiality is about privacy, Integrity is about accuracy and trustworthiness, and Availability is about access when needed.
