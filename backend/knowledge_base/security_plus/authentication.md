
# Authentication and Multi-Factor Authentication

## Definition
Authentication is the process of verifying the identity of a user, device, or system. It helps ensure that only the correct person can access protected resources.

## Key points
- Something you know: a password or PIN.
- Something you have: a security token, smart card, or phone.
- Something you are: a fingerprint, face, or other biometric feature.
- Multi-Factor Authentication (MFA) requires two or more different authentication factor types.
- A strong password should be unique and difficult to guess.
- MFA provides extra protection even if a password is stolen.

## Example
A student logs into a school account using a password and then enters a verification code from an authenticator app. This is MFA because it uses something the student knows and something the student has.

## Exam tip
Two passwords are not MFA because both are the same factor type: something you know. MFA requires different factor types.
